# Human-Centered Public Robotics, CHI 2027 workshop website

Static site served by GitHub Pages from the `main` branch root. No build step.

- `index.html` holds all content. Edit dates, the call for papers, and the program there.
- `styles.css` holds the design tokens at the top (`:root`).
- `assets/` holds web-compressed photos of the simulator and robots.

Before the workshop is accepted, the hero shows a line saying the proposal is under review. Remove it once CHI announces decisions (November 19, 2026), and add the submission link when the call opens (December 17, 2026).
